🀄 設定雲端同步

1建立 Google 試算表

前往 sheets.google.com，新增空白試算表，隨便命名（例如：麻將紀錄）

2開啟 Apps Script

在試算表上方選單點：擴充功能 → Apps Script

3貼上程式碼

把 apps-script.gs 裡的程式碼全部複製，貼到 Apps Script 編輯器，按儲存（Ctrl+S）

4部署為網路應用程式

點右上角 「部署 → 新增部署作業」
類型選 「網路應用程式」
執行身分：「我」
存取權：「所有人」
點部署 → 授權 → 複製「網路應用程式網址」

5貼上網址

把剛才複製的網址貼到下方

設定只需做一次，之後所有裝置開啟即可自動同步
